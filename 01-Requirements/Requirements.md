# Software Requirements

## 1. Login

### RQ-001

The application should allow a valid registered user to log in using valid credentials.

### RQ-002

The application should display an appropriate error message when invalid login credentials are entered.

### RQ-003

The application should validate required login fields.

---

## 2. Product Inventory

### RQ-004

The application should display the available products on the Products page.

### RQ-005

Each product should display relevant information such as product name, description, price, image, and cart action.

### RQ-006

The user should be able to open the product details page.

---

## 3. Product Sorting

### RQ-007

The user should be able to sort products using the available sorting options.

### RQ-008

Products should be displayed according to the selected sorting option.

---

## 4. Shopping Cart

### RQ-009

The user should be able to add a product to the shopping cart.

### RQ-010

The shopping cart should display the number of items currently added.

### RQ-011

The user should be able to view products added to the cart.

### RQ-012

The user should be able to remove products from the cart.

### RQ-013

The cart should display the correct product information, including product name, image, description, price, quantity, and Remove action.

---

## 5. Checkout

### RQ-014

The user should be able to proceed from the cart to checkout.

### RQ-015

The checkout form should require the necessary customer information.

### RQ-016

The user should be able to review the order before completion.

---

## 6. Order Completion

### RQ-017

The user should be able to complete an order successfully using the available checkout flow.

### RQ-018

The application should display an appropriate confirmation after successful order completion.

---

## 7. Logout

### RQ-019

The user should be able to log out of the application.

### RQ-020

After logout, the user should be redirected to the Login page.

---

## 8. Footer Links

### RQ-021

The footer should contain links to the available social media platforms.

### RQ-022

The social media links should navigate to their intended destinations.
