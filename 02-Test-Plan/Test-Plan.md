---

## 2. Objective

The objective of this testing activity is to verify that the major functional workflows of the SauceDemo application operate according to the defined requirements.

The testing focuses on identifying functional issues, validating user workflows, and documenting any confirmed defects.

---

## 3. Scope

### In Scope

* Login
* Product Inventory
* Product Details
* Product Sorting
* Shopping Cart
* Checkout
* Order Completion
* Logout
* Footer Links

### Out of Scope

* Performance Testing
* Security Testing
* API Testing
* Database Testing
* Automation Testing

---

## 4. Testing Approach

The following testing approaches were considered and applied where applicable:

* Functional Testing
* Positive Testing
* Negative Testing
* Boundary Value Analysis where applicable
* Exploratory Testing
* Smoke Testing
* Regression Testing
* Retesting
* Usability Testing
* Compatibility Testing

---

## 6. Entry Criteria

Testing can begin when:

* The application is accessible.
* Test credentials are available.
* Required functionality is available for testing.
* Test cases have been prepared.

---

## 7. Exit Criteria

Testing can be considered complete when:

* Planned test cases have been executed.
* Identified defects have been documented.
* Required retesting has been completed where applicable.
* Test execution results have been recorded.
* Test summary has been prepared.

---

## 8. Deliverables

The following testing documents were produced:

* Requirements
* Test Plan
* Test Scenarios
* Test Cases
* Test Data
* Test Execution Report
* Bug Reports
* Requirement Traceability Matrix (RTM)
* Test Summary

---

## 9. Risks

Possible risks include:

* Application availability issues.
* Browser compatibility issues.
* Unexpected application behavior.
* Requirements not covering all possible user behavior.

---

## 10. Assumptions

* The application is available during testing.
* Provided test credentials are valid.
* Testing is performed using the specified browser and environment.
* The application is treated as a demo application for testing purposes.
